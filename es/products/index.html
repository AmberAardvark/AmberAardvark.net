¿Por qué utilizar un acelerador?

Estos aceleradores reúnen componentes configurables y orientación de implementación para evaluar un punto de partida enfocado.

  • Componentes reutilizables para requisitos comunes de datos y automatización.
  • Patrones documentados que pueden adaptarse a tu entorno.
  • Opciones de código abierto que puedes evaluar antes de iniciar una solución.
